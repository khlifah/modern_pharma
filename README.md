# modern_pharma — نظام إدارة محاسبة وصيدلية

[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

نظرة عامة

نظام لإدارة المحاسبة والمخزون موجه للصيدليات والمتاجر، مبني بلغة PHP مع بنية بسيطة تُسهل النشر والصيانة.

الميزات الأساسية

- إدارة المخزون والمنتجات
- أصناف ومستخدمين وصلاحيات إدارية
- صفحات إدارة لواجهة الويب

المتطلبات

- PHP 7.4 أو أحدث
- MySQL 5.7 أو أحدث
- Composer

التثبيت والتشغيل (محلي)

1. استنساخ المستودع:

```bash
git clone https://github.com/khlifah/modern_pharma.git
cd modern_pharma
```

2. تثبيت التبعيات:

```bash
composer install
```

3. إعداد ملف البيئة:

```bash
cp env.example .env
# ثم عدّل القيم داخل .env مثل إعدادات قاعدة البيانات
```

4. إعداد قاعدة البيانات:

- أنشئ قاعدة بيانات جديدة على MySQL
- نفّذ سكربتات الـ SQL أو شغّل المايجريشن إن وُجدت

5. تشغيل الخادم محلياً (مثال باستخدام built-in PHP server):

```bash
php -S localhost:8000 -t public
```

نشر

يمكن نشر المشروع على أي استضافة تدعم PHP (Shared hosting, Render, أو غيرها). تأكد من:

- إعداد متغيرات البيئة في لوحة الاستضافة
- إعداد اتصال قاعدة البيانات بشكل صحيح

هيكل المشروع (موجز)

- `public/` — ملفات الوصول العام (index.php, assets)
- `includes/` — ملفات مشتركة وتهيئة التطبيق
- `assets/` — CSS وJS وملفات الصور
